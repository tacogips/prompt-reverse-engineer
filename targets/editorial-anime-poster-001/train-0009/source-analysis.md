# Training-source content analysis

## Purpose

This is a source-fidelity record, not prompt material. The training image is a vertically framed photograph of a seated child in an indoor tiled setting. It contains recognizable facial identity, short dark hair, a light short-sleeve graphic shirt, light trousers, a seated side-facing posture, and embedded social-interface-like marks near the lower right.

## Preservation boundary

Candidate generation must retain the source-controlled person, apparent age, facial identity, anatomy, hair, garment identity and markings, pose, crop, and scene unless an explicit optional instruction narrowly overrides the relevant attribute. Stylization must not add adult features, sexualization, injury, or an unrelated subject. No source observation in this file may enter the reusable prompt.
