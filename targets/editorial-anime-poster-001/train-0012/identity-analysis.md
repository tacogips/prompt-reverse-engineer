# Source analysis — train-0012

This compatibility file is intentionally identical in policy to `source-analysis.md`.

`input/source-child.jpeg` is the sole training content reference and the only permissible image input for candidate generation. Its identity, age, anatomy, facial features, hair, apparel, marks, pose, crop, setting, and any visible words are source-controlled facts, not prompt content. Preserve all such content by default. Optional `pose`, `composition`, `text`, and narrowly scoped `additional` instructions may override only their stated attribute. No observed source-specific description is carried into the reusable style prompt.
