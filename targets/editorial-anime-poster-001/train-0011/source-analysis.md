# Source-content analysis boundary

The training image is content truth only. It is a photographic source with a person, visible clothing and garment marking, a seated pose, an indoor setting, and incidental interface graphics. Those specifics must remain source-controlled and must not appear in the learned prompt.

For judging, preserve recognizable source identity and age, anatomy, facial and hair identity, clothing silhouette, garment construction, markings/logos, objects, pose, crop, and scene unless a caller explicitly overrides the named attribute. The transformation may change medium, graphic value grouping, contours, support shapes, and print texture. It must not invent replacement clothing, erase markings, add unrequested readable text, or use the style truth as an input image.
